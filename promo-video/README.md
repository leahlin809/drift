# Drift V1 Promo

24 秒、16:9、无配音的 V1 产品展示短片。

## Storyboard

1. 品牌开场：所见 / Drift
2. Map first：把文化兴趣放回世界里
3. Capture：添加 Entry，并选择国家、城市或 Point
4. Rediscover：从收藏与空间重新发现内容
5. Personal atlas：展示 Entry 的私人笔记
6. 品牌收束：Capture → Spatialize → Rediscover

## Commands

```powershell
npm run studio
npm run render
```

最终文件输出到 `out/drift-v1-promo.mp4`。
