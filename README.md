# 心愿地图

心愿地图是一款围绕“愿望管理、目标拆解、成长记录与可视化路线规划”展开的应用型产品。它帮助用户把抽象愿望转化为清晰的行动地图，并通过结构化记录保持长期执行。

## 项目目标
- 让用户把愿望、计划和行动连接起来。
- 提供清晰的目标拆解和阶段展示。
- 通过地图式结构帮助用户理解进度与关系。
- 支持长期记录、复盘和调整。
